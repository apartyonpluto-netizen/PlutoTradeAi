  • OFF — no automated activity of any kind. Existing positions/pending orders are still monitored and protected.
  • SCOUT / ANALYST — reserved for future review-only workflows. Today these behave identically to OFF: nothing is submitted automatically.
  • PAPER — manual sandbox trading. You review opportunities and place orders yourself from the dashboard; nothing is submitted automatically in this mode.
  • APPROVAL — reserved for a future per-trade approval queue. Today this also behaves like OFF: no automatic submission, and there is no approval queue built yet.
  • AUTONOMOUS — the only mode that submits sandbox orders automatically and unattended, on the external scheduler's own cadence. See Scan Run History below to confirm it is actually running for this account before relying on it.

Do not switch to AUTONOMOUS yet: the scheduler currently driving this (a GitHub Actions cron job, not a dedicated Render worker) has an observed real-world cadence of roughly once per hour rather than every 5 minutes, and the continuous 5–10 second order-safety monitor this app was built to require before unattended trading is not yet deployed. Existing-position monitoring (protecting anything already open) is independent of mode and unaffected by this.

Sandbox only — live real-money execution stays locked regardless of mode.
